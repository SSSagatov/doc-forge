# doc-forge

Проект находится в разработке. Пока в нём доступна проверка подключения к базе данных PostgreSQL. Ниже — всё, что нужно для первого запуска.

## Что понадобится

- Go версии 1.25 или новее.
- Запущенный PostgreSQL на вашем компьютере или доступ к нему на другом сервере.
- Название базы данных, имя пользователя и пароль для подключения.
- Интернет при первом запуске для загрузки необходимых компонентов.

## Как запустить

### 1. Откройте папку проекта

Откройте терминал в папке, где находятся файлы `go.mod` и `.env.example`. Все команды ниже нужно выполнять в этой папке.

Загрузите необходимые компоненты:

```sh
go mod download
```

### 2. Создайте файл настроек

Сделайте копию `.env.example` и назовите её `.env`. Если `.env` уже есть, откройте его для редактирования.

В Windows PowerShell копию можно создать командой:

```powershell
Copy-Item .env.example .env
```

В Linux или macOS:

```sh
cp .env.example .env
```

### 3. Укажите данные для подключения

Откройте `.env` в текстовом редакторе и заполните настройки:

```dotenv
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=postgres
DB_SSLMODE=disable
```

| Настройка | Что указать |
| --- | --- |
| `DB_HOST` | `localhost`, если PostgreSQL установлен на вашем компьютере. Иначе — адрес сервера. |
| `DB_PORT` | Обычно `5432`. Меняйте, только если PostgreSQL настроен на другой порт. |
| `DB_USER` | Имя пользователя PostgreSQL. |
| `DB_PASSWORD` | Ваш пароль вместо `your_password`. |
| `DB_NAME` | Название уже существующей базы данных. |
| `DB_SSLMODE` | Для примера с локальной базой оставьте `disable`. Для удалённой базы используйте значение, предоставленное её администратором. |

Сохраните файл. Приложение прочитает его при проверке подключения.

### 4. Проверьте подключение

Выполните:

```sh
go run cmd/app/main.go --test-db
```

Если всё настроено правильно, появится сообщение:

```text
PostgreSQL connection test passed
```

Это значит, что подключение работает. После проверки программа завершится. Данные в базе не изменятся.

## Короткая команда

Если у вас установлен Make, ту же проверку можно запустить так:

```sh
make test
```

Если появляется ошибка `No rule to make target 'test'`, убедитесь, что открыта папка проекта, и попробуйте:

```sh
make -f Makefile test
```

Make устанавливать необязательно: команда `go run cmd/app/main.go --test-db` выполняет ту же задачу.

## Если что-то не работает

| Что произошло | Что проверить |
| --- | --- |
| Команда `go` не найдена | Установите Go и заново откройте терминал. |
| Сообщение `failed to load .env` | Убедитесь, что файл называется именно `.env`, а не `.env.txt`, и находится в папке, из которой вы запускаете команду. |
| Сообщение `password authentication failed` | Проверьте `DB_USER` и `DB_PASSWORD` в `.env`. |
| Сообщение `connection refused` или долгое ожидание | Убедитесь, что PostgreSQL запущен, а адрес и порт указаны правильно. |
| Сообщение о том, что база не существует | Проверьте `DB_NAME`. Приложение не создаёт базу автоматически. |
| Программа завершилась без сообщения | Для проверки подключения добавьте `--test-db`, как в примере выше. Запуск без этого параметра пока ничего не выполняет. |
